# \# ISIA — Information, Support, and Inspiration for All

# 

# A Flutter mobile application providing school communication and student engagement features for Senior High School students and faculty of St. Nicolas Golden Field Academy Inc.

# 

# \## 📱 Features

# 

# \### For Students

# \- Section-targeted announcements with push notifications

# \- Weekly class schedule with day tabs

# \- Deadlines and exam tracking with countdown

# \- School events

# \- Support contacts and feedback submission

# \- Mood check-in

# \- Interactive polls

# \- Bible verses and motivational quotes

# \- Keyword search across all content

# \- Notification history

# 

# \### For Teachers

# \- Post announcements to specific sections or all

# \- Manage class schedules (with overlap prevention)

# \- Manage deadlines, events, support contacts

# \- Post custom verses and quotes

# \- Create interactive polls

# \- View student mood check-ins (section-filtered, daily-expiring)

# \- Read student feedback

# \- Delete own announcements

# 

# \## 🛠️ Tech Stack

# 

# \- \*\*Frontend:\*\* Flutter, Dart, Material 3

# \- \*\*Backend:\*\* Firebase (Authentication, Cloud Firestore, Cloud Messaging)

# \- \*\*Push Notifications:\*\* FCM HTTP v1 API with Google Service Accounts

# \- \*\*Platform:\*\* Android (min SDK 23)

# 

# \## 🚀 Setup

# 

# \### Requirements

# \- Flutter SDK 3.9+

# \- Android Studio

# \- Firebase project

# 

# \### Steps

# 1\. Clone this repository

# 2\. Run `flutter pub get`

# 3\. \*\*Add the following files\*\* (not included in repo for security):

# &#x20;  - `android/app/google-services.json` — Firebase Android config

# &#x20;  - `assets/service-account.json` — Firebase service account for FCM

# 4\. Configure Firestore rules (see `docs/firestore-rules.txt`)

# 5\. Run `flutter run`
